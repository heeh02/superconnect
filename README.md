# Superconnect · v0.2.2 免费开源预览版

把 Mac 的画面放到 Android 设备上，让平板成为一块扩展屏。

本版面向 **Mac → Android**，也支持在华为平板的 **卓易通** 中运行 Android 接收端。
不需要付费或邮箱登录。它不是鸿蒙原生版，也不是四平台互投正式版。

## 本轮功能

- 暖色界面：先在预览区域看画面，再进入全屏；控制条靠边隐藏，可返回预览。
- H.264 画面传输，设备之间需要配对确认，连接使用认证和加密记录。
- 单指点按与拖动；双指轻点右键、上下/左右滚动与捏合缩放。
- 手写笔笔压/倾斜、手掌防误触，以及可选“手指当笔”和“触控笔绘画模式”。
- 在 Mac 中主动开启“允许平板触控、手写笔与键盘”后，控制才生效；仅观看不要求辅助功能。
- 画质提供流畅 25 Mbps、均衡 50 Mbps、极致 80 Mbps，并保留 10–100 Mbps 调节。
- 文件传输暂未开放，界面以锁标志注明“后续解锁”。

发布页记录这一组最终源码和制品的实际验收范围。单台华为平板的卓易通结果不等于
所有 Android/鸿蒙设备兼容；不承诺专业绘图软件全部识别压感，也不宣称逆向投屏、
HDC 有线媒体链路或原生鸿蒙已经完成。未按可复现方法测量的延迟仍记为未测量。

## 安装与连接

本版提供 Android **arm64** APK、对应源码，以及仅适用于 Apple Silicon 的实验性 Mac ZIP。
Mac ZIP 使用 Apple Development 开发签名，未做 Developer ID 签名或苹果公证，Gatekeeper
可能拒绝直接打开；不要关闭 Gatekeeper。也可以按源码说明自行构建匹配的 Mac 端。
旧 `v0.2.0` Mac 安装包不能连接本版的新加密协议。

1. 下载发布页明确标注的实验性 Mac ZIP，或按 [Mac 构建说明](mac/FOSS_PREVIEW_SOURCE_BUILD.md) 构建。
2. Android 设备安装本版 APK；华为平板请使用卓易通安装并打开。
3. 两端连接同一个 Wi-Fi。平板显示地址后，在 Mac 中添加该地址和端口 `18888`。
4. 首次连接在设备上确认配对，Mac 允许屏幕录制。
5. 若需要触控、手写笔和键盘，在 Mac 中开启平板控制并允许辅助功能。
6. 保持接收端在前台；使用“进入全屏”和靠边隐藏的“退出全屏”切换显示模式。

本次卓易通验证使用 Wi-Fi。连接调试线不代表媒体经过 USB；
Harmony 调试工具的转发不能直接连接卓易通 Android 容器的本机回环端口。

## 预览版与升级限制

- Android 包名是 `com.superconnect.receiver.foss`，与旧版及 root/付费版分开，不迁移它们的数据。
- APK 为明确标记的 **Debug 签名预览包**，不是正式市场包。官方 v0.2.2 资产沿用
  v0.2.1 的同一调试证书，可原位更新该预览安装；将来改用正式签名仍可能需要卸载，
  并导致本应用的配对记录丢失。
- macOS 最低 14。Apple Silicon 本地构建已验证；Intel 源码目标存在，但本轮未做运行验证。
- 实验性 Mac ZIP 不代表普通签名/公证交付，也不保证未来正式签名版本原位升级或权限延续。

## 开发与源码范围

本版沿用同一套 Rust 认证、加密记录、会话和编码实现，只导出这条用户流程使用的源码。
本版只公开该流程需要的触控/手写笔手势适配；高级连接/媒体恢复、UDP 视频、
付费授权和其他平台实现不进入新增公开内核范围。
预览版 ABI 是这份裁剪源码的独立身份，不可与付费内核静态库混用。
